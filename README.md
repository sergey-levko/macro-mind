# MacroMind

AI-powered nutritional tracking & personalized meal intelligence.

Log daily meals against the USDA FoodData Central database, visualize macro progress, and receive AI-generated nutrition insights powered by Claude.

## Features

- **Meal logging** — search the USDA FoodData Central database, log foods per meal type, and track daily intake against calorie and macro goals
- **Dashboard** — day-by-day macro breakdown, weekly calorie chart, and intake progress bars
- **Recent foods & copy day** — quick-add from recently used foods; copy the previous day's meals in one click
- **Meal templates** — save a meal section as a named template and re-apply it on any future day with custom quantities
- **AI Coach** — on-demand daily and weekly insights generated by Claude AI; proactive overnight scheduling generates insights automatically for every active user
- **Insight history** — browse past daily and weekly insights; delete outdated entries
- **Authentication** — JWT-based login with short-lived access tokens and DB-backed refresh token rotation; update password from settings
- **Onboarding** — new users are guided through goal setup before reaching the dashboard

## Prerequisites

- Java 21
- Maven 3.9+
- Node.js 20+
- Docker & Docker Compose

## Quick Start

### 1. Start the database

```bash
docker compose up -d
```

PostgreSQL 16 starts on `localhost:5432` (database: `macromind`, user: `macromind`, password: `macromind`).

### 2. Run the backend

```bash
cd backend
./mvnw spring-boot:run
```

The API starts on `http://localhost:8080`.

> **AI features** require an Anthropic API key:
> ```bash
> export ANTHROPIC_API_KEY=sk-ant-...
> ```

### 3. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

The app opens at `http://localhost:5173`. API calls are proxied to the backend automatically.

### 4. Verify

```bash
curl http://localhost:8080/api/v1/health
# {"status":"UP"}
```
