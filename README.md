# MacroMind

AI-powered nutritional tracking & personalized meal intelligence.

Log daily meals against the USDA FoodData Central database, visualize macro progress, and receive AI-generated nutrition insights powered by Claude.

## Features

- **Meal logging** — log foods by meal type (Breakfast, Lunch, Dinner, Snack); search custom and USDA foods; create new foods inline; edit and remove logged items; navigate by date with a calendar picker
- **Recent foods** — quick-add from up to 10 most recently used foods without typing a search
- **Meal templates** — save any meal section as a named template and re-apply it on any future day with custom quantities per item
- **Dashboard** — daily macro progress bars (calories, protein, carbs, fat vs. targets), weekly calorie bar chart, and day-by-day navigation
- **Food catalog** — manage custom foods; search and import from USDA FoodData Central (800k+ foods); toggle USDA integration on or off per user
- **AI Coach** — on-demand daily and weekly nutrition insights generated by Claude AI; automatic overnight generation for all active users; browsable insight history with delete support
- **Nutritional goals** — set calorie and macro targets manually or generate personalized suggestions via Claude AI using your profile data
- **Settings** — enable or disable the USDA food database integration per account
- **Profile** — update name, age, weight, height, and goal type; change password
- **Authentication** — JWT-based login with short-lived access tokens and DB-backed refresh token rotation
- **Onboarding** — first-time users are guided through goal setup before reaching the dashboard

## Prerequisites

- Java 21
- Maven 3.9+
- Node.js 20+
- Docker & Docker Compose

## Quick Start

### 1. Start the database

```bash
docker compose up -d
```

PostgreSQL 16 starts on `localhost:5432` (database: `macromind`, user: `macromind`, password: `macromind`).

### 2. Run the backend

```bash
cd backend
./mvnw spring-boot:run
```

The API starts on `http://localhost:8080`.

> **API keys** are required for full functionality:
> ```bash
> export ANTHROPIC_API_KEY=sk-ant-...   # AI Coach and goal suggestions
> export USDA_API_KEY=...               # USDA FoodData Central food search and import
> ```

### 3. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

The app opens at `http://localhost:5173`. API calls are proxied to the backend automatically.

### 4. Verify

```bash
curl http://localhost:8080/api/v1/health
# {"status":"UP"}
```
